# F1lytics SEO content roadmap

This roadmap starts with the existing 2026 product. It does not authorize mass-generated pages or a multi-season expansion.

| Cluster | Existing destination | Initial action |
| --- | --- | --- |
| 2026 standings/results/calendar | `/standings`, `/races`, `/calendar` | Improve titles, descriptions, linking, and data freshness. Compete on usefulness, not duplicated editorial copy. |
| Free F1 live timing | `/live` | Expand its crawlable introduction and limitations; link from About and relevant race pages. |
| F1 telemetry explained | Race telemetry sections | Prepare an evergreen guide brief only after query validation. |
| F1 tyre strategy/undercut/stints | Race strategy sections | Prepare an evergreen guide brief with examples and visual links. |
| Driver/team comparisons | `/compare` | Measure demand before creating indexable pair pages; do not generate all combinations. |
| Circuit and race-specific queries | Existing circuit/race pages | Use state-aware metadata, cross-links, and unique factual summaries. |

## Day-28 decision gate

After 28 days of Google Search Console data:

1. Improve pages with high impressions and below-site-average click-through rate.
2. Prioritize relevant queries ranking in positions 8–30.
3. Publish at most two evergreen guides, each with source citations, original diagrams or data examples, and links into race/live tools.
4. Do not create historical-season pages until F1lytics has a deliberate multi-season data model.

Review Search Console weekly for the first month and monthly afterward. Track indexed pages, exclusions, clicks, impressions, CTR, average position, queries, landing pages, and mobile Core Web Vitals.
